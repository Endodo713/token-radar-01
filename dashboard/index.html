How the value is priced

implied = TVL × category median (FDV/TVL) × growth × maturity

1 · Comparables, not a fixed multiple

Each protocol is priced at the median FDV/TVL of live-token protocols in its own category. Lending trades near 0.13× TVL, DEXes near 0.34×, liquid staking near 0.03×. A category with fewer than five live protocols falls back to the global median (). The multiple is printed on every row, with its source, so the board can be checked line by line.

2 · Growth and age

Seven-day TVL change, clamped to −60%…+120%, moves the value by half its size. A protocol tracked longer with no token yet counts more: maturity runs 0.60 for a newborn to 1.00 after three years. Nothing in the model names a protocol: the same function scores every row.

3 · What “no token” means

“Pre-token” means DefiLlama’s record carries no token for the protocol. It is not proof the protocol has none, and it is not a prediction that one will be issued, or when. A board’s implied value is this entry’s own claim, never make.fun’s.
